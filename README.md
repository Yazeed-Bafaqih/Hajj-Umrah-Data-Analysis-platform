# منصة بيانات وذكاء أسواق الحج والعمرة

> **Prototype — نموذج أولي غير مخصص للاستخدام الرسمي**

منصة بيانات عربية صُممت لتكون مرجعًا تحليليًا لمركز تحليل البيانات وذكاء الأعمال، وتجمع مؤشرات الدول وأسواق الحج والعمرة والباقات والمقارنات في واجهة موحدة.

هذا المستودع مخصص لعرض الفكرة والتصميم والتفاعلات فقط. بيانات الحج والعمرة والباقات داخله بيانات تجريبية `Dummy Data` ولا تمثل إحصاءات أو أسعارًا رسمية.

## محتويات النموذج

- نظرة تنفيذية لأبرز مؤشرات السوق.
- مستكشف للدول والاقتصادات مع البحث والتصفية.
- تحليل تجريبي للحج: المتقدمون، الحصص، والدخول الفعلي.
- تحليل تجريبي للعمرة عبر المواسم.
- أداة لمقارنة دولتين إلى أربع دول.
- مقارنة باقات الحج والعمرة ومكونات فجوة السعر.
- توضيح مصدر البيانات وطريقة حساب المؤشرات المشتقة.
- واجهة عربية متجاوبة مع الشاشات المختلفة.

## البيانات

| النوع | المصدر والحالة |
|---|---|
| المؤشرات العامة للدول | بيانات من ملف البنك الدولي المستخدم في النموذج |
| الحج والعمرة | بيانات تجريبية مولدة لاختبار التصميم |
| الباقات والأسعار | بيانات تجريبية وليست عروضًا أو مدفوعات فعلية |

## التشغيل محليًا

لأن الموقع يقرأ ملفات JSON محلية، شغّله من خلال خادم محلي بسيط بدل فتح `index.html` مباشرة.

```bash
python3 -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173
```

يمكن كذلك استخدام إضافة **Live Server** في VS Code.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح إعدادات المستودع `Settings`.
3. اختر `Pages`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.

سيظهر رابط الموقع بعد اكتمال النشر بدقائق قليلة.

## حدود الاستخدام

- النموذج لا يحتوي على نظام دخول أو قاعدة بيانات أو خادم خلفي.
- لا تستخدم بيانات سرية أو تشغيلية داخل مستودع عام.
- يجب استبدال البيانات التجريبية بمصادر رسمية معتمدة قبل أي استخدام فعلي.
- الشعارات والخطوط والهوية البصرية تخضع لحقوق أصحابها ولا يشملها أي ترخيص برمجي افتراضي.
